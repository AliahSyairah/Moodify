# Moodify - Adaptive Music & Visual Recommendation (Mobile App)

Mobile application frontend for Moodify, built with Flutter SDK. Features real-time facial emotion recognition integration, dynamic UI visual theme adjustments, and music streaming mapped to emotional states.

## 🛠️ Tech Stack & Dependencies
- **Frontend Framework:** Flutter SDK (Dart)
- **State & UI Management:** Dynamic Themes, Custom Visual Routers
- **AI & Edge Integration:** Google ML Kit Face Detection
- **Backend Communication:** REST API Client (Python/Flask backend), Firebase Cloud Firestore

## 📁 Architecture Overview
- `lib/screens/`: Authentication, Home, Emotion History, Music Player UI
- `lib/services/`: API Services, Cloudinary, YouTube Streamer, Session Handler
- `lib/providers/`: State management and data flow
